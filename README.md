# Linux Command Line Practical Task

A GitHub-ready evidence workspace for completing the **Linux Command Line Practical Task** in Kali Linux as the newly created user `student01`.

## Objective
Demonstrate basic Linux command-line skills by creating and switching to a user, managing directories and files, editing and moving files, setting permissions with `chmod`, cleaning up, and verifying the final project structure.

## Lab environment
- Operating system specified by the task: Kali Linux
- Required user: `student01`
- Project directory: `~/project`

## Repository layout

```text
linux-command-line-practical-task-02/
├── README.md

│   ├── COMMAND_WALKTHROUGH.md
│   └── TASK_CHECKLIST.md
├── evidence/
│   ├── README.md
│   └── screenshots/
│       └── .gitkeep
├── notes/
│   └── RESULTS_TEMPLATE.md
└── reference/
    └── EXPECTED_STRUCTURE.md
```

The `project/` directory is created inside the Kali Linux user's home directory while you perform the lab; it is not a substitute for the evidence repository structure above.

## Quick start
1. Open `instructions/COMMAND_WALKTHROUGH.md` and carry out each step in Kali Linux.
2. Capture your own screenshots and save them under `evidence/screenshots/`.
3. Record any differences or issues in `notes/RESULTS_TEMPLATE.md`.
4. Compare your final output with `reference/EXPECTED_STRUCTURE.md`.
5. If you complete the optional bonus, save `commands_used.txt` in `student01`'s home directory and document it in your evidence.

## Safety and accuracy
- Run commands in your Kali Linux lab environment, not on a production machine.
- Use the exact username, filenames, and required file contents from the task.
- The password is entered interactively; do not write it in this repository or in screenshots.
- Do not claim a step is complete until you have performed it and captured evidence.
- The task says to add `student01` to the `sudo` group **if required**. Follow your lab's account policy.
- The task says to install `tree` only if it is not already installed.
