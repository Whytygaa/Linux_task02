# Evidence and Screenshots

Save screenshots you capture yourself in `screenshots/`. The task does not prescribe exact screenshot filenames, so the following are suggested names for clear portfolio documentation:

1. `01-user-created-and-whoami.png` — show `whoami` returning `student01`.
2. `02-project-directories-and-hidden-file.png` — show directory creation and `ls -la`.
3. `03-report-edited-and-files-moved.png` — show the two report lines and resulting file locations.
4. `04-permissions.png` — show `ls -l` output for `install.sh`, `classified.txt`, and the temporary `admin_notes.txt` before deletion if captured during that step.
5. `05-final-tree-and-listing.png` — show `tree project` and final `ls -la` output.
6. `06-command-history-optional.png` — only if you complete the optional bonus.

## Evidence rules
- Use genuine screenshots from your own lab session.
- Keep terminal output legible and include the command where practical.
- Do not include passwords, access tokens, personal information, or unrelated desktop content.
- Do not create fake screenshots or imply a command succeeded if it did not.
- `.gitkeep` only keeps this folder visible in Git; replace it with your actual evidence files.
